# 문서 인덱스

## 목적

이 문서 세트는 웹/앱 서비스 구축과 테스트 하네스 엔지니어링을 단계별로 진행하기 위한 기준이다.

## 1차 구축 순서

### 1단계: 공통 작업 규칙 정의

- `AGENTS.md`
- `CLAUDE.md`
- `MEMORY.md`

완료 기준:

- 에이전트가 같은 작업 규칙을 공유한다.
- 프로젝트 특성과 미정 항목을 기록할 위치가 있다.
- 다음 실행과 반복 루프에서 참고할 이슈 트래커가 있다.

### 2단계: 제품/기술 명세 작성

- `docs/01-product-spec.md`

완료 기준:

- 기능 요구사항, 핵심 사용자 흐름, UI/UX, 기술 명세, 데이터 규칙이 한 문서에 정리된다.
- 개발자와 AI가 구현 맥락을 이해할 수 있다.

### 3단계: 테스트 전략 작성

- `docs/02-test-strategy.md`

완료 기준:

- 제품 정의를 바탕으로 Unit, Component, Integration, Contract, E2E 테스트 항목이 정리된다.
- 테스트 하네스 구조, fixture, factory, mock, seed 기준이 정리된다.

### 4단계: 품질 게이트 정의

- `docs/03-quality-gates.md`

완료 기준:

- 타입체크, lint, 테스트 명령 기준이 정리된다.
- 코드 프로젝트가 생긴 뒤 적용할 검증 순서가 정의된다.

## 현재 상태

- 1차 문서 골격 생성
- 요구사항과 사용자 흐름은 `docs/01-product-spec.md`로 통합
- 테스트 전략과 하네스 구조는 `docs/02-test-strategy.md`로 통합
- 실제 코드 프로젝트 없음
- `tsc --noEmit`/lint 실행 대상 없음
